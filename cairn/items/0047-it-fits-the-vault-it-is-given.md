Obsidian is closed source, so there is nothing to read. The vault is not: its
`.obsidian/` directory records exactly which features this reader uses and how
they have them set, which is a better specification than any feature list.

Most of what it asks for is already built — the settings independently confirm
v0.5. What remains is the vault's own conventions: its templates, its periodic
notes, where new files and attachments belong, and the reading mode it is
already configured for.
