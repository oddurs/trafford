# Welcome

A vault is a folder of markdown files. trafford reads it the way Obsidian
does — `[[wikilinks]]`, backlinks, tags — and edits it the way vim does.

Start with [[How linking works]], then look at [[Reading a note]].

> [!tip] Everything here is clickable
> Right-click any surface for what can be done to it.
